1. Overview: What the parser does

The HNET parser takes a natural language phrase and finds the most natural way to group its words into hierarchical pairs. Rather than using handwritten grammar rules, it relies entirely on distributional statistics: two elements naturally group together when they appear in each other's context spaces — when words that follow the left element commonly precede the right element, and vice versa.

The core loop is an incremental bottom-up (CKY-style) chart parser. As each new word arrives, all sub-spans ending at that word are analyzed. For every possible binary split of a span, the parser runs a 4-step mutual expansion that generates substitution classes for both sides, filtered by consensus contexts. The split with the lowest energy (most coherent substitution class) is selected as the preferred grouping.

Key concepts

  • Unit: any word or phrase registered in the catalog, characterized by its left and right context word distributions
  • Substitution class: the set of other units that could fill the same structural slot
  • Energy: a scalar measuring how well-defined (large, diverse, compositional) a unit's substitution class is — lower is better
  • Mutual expansion: 4-step iterative refinement of both sides of a split using each other's contexts

2. Units, Contexts, and the Catalog

Every word and phrase is represented as a ContextPattern — a distributional fingerprint derived from corpus co-occurrence statistics (built from the Cornell Movie Dialogs corpus):

# bidir_simple.py
@dataclass
class ContextPattern:
    left_words:  Counter   # words observed immediately preceding this unit
    right_words: Counter   # words observed immediately following this unit
    count:       int       # raw corpus frequency

For example, actual catalog entries for "found" and "hat":

left_words of "found" (top from corpus)
i, she, he, they, we, you,
you've, they've, i've, she'd, ...
right_words of "hat" (top from corpus)
on, off, and, ,, shop, .,
rack, trick, in, — ...

The UnitCatalog (47,425 units built from the corpus) stores all units and builds GPU-resident dense vectors from their context distributions. When the parser synthesizes a new multi-word span (e.g., "should go"), it is dynamically added to the catalog with contexts built from its constituents, making it immediately available for scoring in parent spans.

Containment Scoring

The primary scoring method asks: how well does a candidate fit into a target's context space?

# bidir_simple.py -- gpu_contextual_candidates()
# For candidate C scored against target T:
left_score  = |C.left_words  ∩ T.left_words|  / |C.left_words|
right_score = |C.right_words ∩ T.right_words| / |C.right_words|
score = (left_score + right_score) / 2

This is unidirectional (asymmetric): it measures how much of the candidate's context is covered by the target's context, not symmetric similarity. This preserves minority meaning variants: if "hat" appears after {a, the, my, your, big, small, ...}, then big hats and small hats both score equally even though each covers only a small slice of the full context set.

GPU acceleration: context patterns are stored as float16 vectors on GPU (top 1000 context words per direction, L2-normalized). Cosine similarity over these vectors is available as an alternative, with optional IC-weighting to boost rare, informative context words.

3. The Energy Function

For each span/split pair, the parser computes an energy scalar measuring how well-defined and compositional the resulting substitution class is. Lower energy = better-defined, more natural grouping.

E = −log(num_subs) + log(consensus) − log(full_length_subs)
TermMeaningEffect
−log(num_subs) More substitutes → lower energy. A rich substitution class (e.g., 1500 for "we should") indicates a stable, well-attested structural pattern. More subs = better ↓
+log(consensus) Lower consensus (more diversity in context words across substitutes) → lower energy. High diversity means the unit appears in varied distributional contexts — it is compositional rather than idiomatic. More diverse = better ↓
−log(full_length) More substitutes matching the same word-count structure as the original → lower energy. Length-preserving substitutions indicate a productive compositional slot. More length-matches = better ↓

4. The 4-Step Mutual Expansion

For a split left_text | right_text, the algorithm generates substitution candidates via four steps of alternating feedforward and disinhibition — mirroring the neural FF→DIS cycle.

left_text right_text | | | eff_right (right-contexts) | eff_left (left-contexts) v v +-------------------------------------------------+ | STEP 1: LEFT_SUBS (Feedforward) | →FF | Score right.eff_left against left_text | | → substitutes for LEFT in LEFT's context | +-------------------------------------------------+ | | | | left.eff_right (right contexts) v v +-------------------------------------------------+ | STEP 2: RIGHT_SUBS (Disinhibition) | ←DIS | Score left.eff_right against right_text | | → substitutes for RIGHT in RIGHT's context | +-------------------------------------------------+ | | | consensus right_words | | from STEP 1 substitutes | v v +-------------------------------------------------+ | STEP 3: RIGHT_CANDS (FF cycle 2) | →FF | Re-score right_text against consensus | | right-contexts of STEP 1 substitutes | +-------------------------------------------------+ | | | consensus left_words | from STEP 2 substitutes v v +-------------------------------------------------+ | STEP 4: LEFT_CANDS (DIS cycle 2) | ←DIS | Re-score left_text against consensus | | left-contexts of STEP 2 substitutes | +-------------------------------------------------+ | | +-- cartesian product: (left_cand, right_cand) pairs --+ filtered by catalog membership = final COMBINED substitutes

Context source: Aggregate left_words from Step 2 substitutes (pronoun forms' left contexts)
Filter: consensus words from ≥30% of right_subs
Re-score: "we" against this consensus pool
Corpus result (from raster, T4):

they   she   there   who   just   he   i   it   you   this

Converged pronoun+demonstrative subject class. Neural map: T4 ←DIS cycle 2

Why two cycles? The first pass (Steps 1–2) uses the raw effective contexts of each side. The second pass (Steps 3–4) uses contexts filtered by consensus across all first-pass substitutes. This removes idiosyncratic co-occurrences and keeps only the bridges that appear robustly across the whole substitution class.

5. Incremental CKY Parsing Loop

The parser processes words left-to-right. When word k arrives, it evaluates all subspans ending at position k, in order of increasing length. This CKY ordering ensures shorter spans (already cached) are available to bootstrap longer ones.

# analyze_phrase.py -- analyze() core loop (simplified)
for k, word in enumerate(tokens):
    # Process all spans ending at position k, shortest first
    for start_pos in range(k, -1, -1):
        span_text = " ".join(tokens[start_pos:k+1])
        # Test all binary splits of this span
        for split_pos in range(k, start_pos, -1):
            left_text  = " ".join(tokens[start_pos:split_pos])
            right_text = " ".join(tokens[split_pos:k+1])
            # Retrieve cached contexts for left and right
            left_entry  = subparse_cache.get(left_text)
            right_entry = subparse_cache.get(right_text)
            # Run 4-step mutual expansion
            subs, eff_left, eff_right, energy, origins = \
                mutual_expand(left_entry, right_entry, catalog)
            # Cache this split
            subparse_cache[(span_text, (left_text, right_text))] = \
                (subs, eff_left, eff_right, energy, origins)

Word arrivesSpans analyzedSplits tested

k=1: "should" "should", "we should" "we" | "should"
k=2: "go" "go", "should go", "we should go" "should" | "go"  ·  "we should" | "go"  ·  "we" | "should go"

Split A (AB|C): "we should" | "go"

E(combined) = (computed from expansion)

A|BC wins for "we should go": the modal+verb unit "should go" has a strong, well-defined substitution class (1500 members), and "we" attaches as a single-word subject. 6. Mapping to the Neural Timeline

The timeline_parse.py code implements the same expansion algorithm as a sequence of discrete neural time steps: alternating feedforward (→FF, orange) and disinhibition (←DIS, blue) cycles that visibly converge both sides of each split.

Each word arrival triggers approximately four FF↔DIS cycles (~100ms each) before the next word arrives (~400ms later). By T4, both sides have stabilized. When the third word C arrives, the DIS step from C's left-context simultaneously acts as the three-element competition that selects the parse structure.

Time bin Neural event Parser step in analyze_phrase.py Population
T0 A arrives ("we") Bootstrap: catalog lookup for left_words, right_words INPUT
T1 B arrives; →FF cycle 1 STEP 1: score right.eff_left against A — left substitutes FF
T2 ←DIS cycle 1 STEP 2: score left.eff_right against B — right substitutes DIS
T3 →FF cycle 2 (refined) STEP 3: consensus right_words of T1 subs → refined right candidates FF
T4 ←DIS cycle 2 (converged) STEP 4: consensus left_words of T2 subs → converged left candidates DIS
T5 C arrives; →FF Right-contexts of T4 unit scored against C — feedforward from converged AB FF
T6 ←DIS *C — competition C's left-context disinhibits antecedent; 3-element asymmetry forces parse selection:
COMP_AB: AB|C — entire AB unit replaced by 2-word bigrams
COMP_A: A|BC — only A replaced by 1-word substitutes		 COMP_AB / COMP_A
T7 →FF continuation Feedforward from competition winners:
FF_AB: 1-word C-class verb substitutes (AB|C continuation)
FF_A: 2-word BC-class (modal+verb) bigrams (A|BC continuation)		 FF_AB / FF_A

Parse-width asymmetry

The output width of each competition population directly encodes the parse structure. The asymmetry is visible in the raster — COMP_AB rows have multi-word entries, COMP_A rows have single words:

AB|C parse (COMP_AB)
RIGHT = C alone • LEFT = entire AB unit
2-word bigram output replacing AB:
they hadda • they wont • sure hadda • sure wont • she hadda • she wont ...
A|BC parse (COMP_A)
RIGHT = BC as a unit • LEFT = A alone
1-word subject output replacing A:
well • cowgirls • no-one • madam • nanobot • voyage • ours • loyalty ...

The structural asymmetry is directly readable from the raster: COMP_AB rows contain multi-word entries; COMP_A rows contain single words. This is not a labeling convention — it emerges from the parse topology itself. The energy minimization selects A|BC as the winner for "we should go" (E=−14.94), but both paths are computed and displayed.

7. Worked Example: "we should go"

T0 — "we" arrives

The word "we" is looked up in the catalog. Its left_words and right_words are loaded as the bootstrap context. No split is possible for a single word.

# timeline_parse.py
w0 = "we"
emit(0, 'INPUT', [(w0, 1.0)])

T1 — "should" arrives; →FF cycle 1

STEP 1 (LEFT_SUBS): score words from "should"'s left-context (right.eff_left) against "we"'s distributional fingerprint.

# STEP 1: right.eff_left scored against left_text ("we")
left_1 = gpu_contextual_candidates(target=w0, candidates=right_eff_left, ...)
emit(1, 'INPUT', [(w1, 1.0)])
emit(1, 'FF', left_1[:top_n])

Corpus result: oughtta, hadda, wont, needn't, oughta, cant, approached, mustn't, survived, attended — the colloquial/dialectal modal-like forms that occupy the same subject+modal slot as "should" in the movie dialog corpus.

T2 — ←DIS cycle 1

STEP 2 (RIGHT_SUBS): score "we"'s right-context words (left.eff_right) against "should"'s distributional fingerprint.

right_1 = gpu_contextual_candidates(target=w1, candidates=left_eff_right, ...)
emit(2, 'DIS', right_1[:top_n])

Corpus result: they've, they, sure, she, there, who, just, he, i, it — pronoun/demonstrative subject forms.

T3 — →FF cycle 2 (refined)

STEP 3 (RIGHT_CANDS): collect the right_words from T1's modal burst (consensus across ≥2 substitutes). Re-score "should" against this consensus pool.

ff1_pool = consensus_ctx(left_1[:top_n], catalog, corpus_index,
                         side='right', min_count=2)
left_2   = score_subs(catalog, w1, ff1_pool, max_n)
emit(3, 'FF', left_2)

Corpus result: oughtta, hadda, wont, pretends, pretended, needn't, ort, dreamt, oughta, couldnt — second cycle consolidates the modal-form class.

T4 — ←DIS cycle 2 (converged)

STEP 4 (LEFT_CANDS): collect left_words from T2's pronoun burst (consensus). Re-score "we" against this pool.

dis1_pool = consensus_ctx(right_1[:top_n], catalog, corpus_index,
                          side='left', min_count=2)
right_2   = score_subs(catalog, w0, dis1_pool, max_n)
emit(4, 'DIS', right_2)

Corpus result: they, she, there, who, just, he, i, it, you, this — converged subject class.

T5 — "go" arrives; →FF

The third word "go" arrives. The converged subject class from T4 is used to drive scoring of verb substitutes.

w2     = "go"
left_3 = score_subs(catalog, w2, ff_pool_from_right_2, max_n)
emit(5, 'INPUT', [(w2, 1.0)])
emit(5, 'FF', left_3)

Corpus result: split, read, use, kill, help, find, make, take, see, get — infinitive/bare verbs that appear in the same slots as "go" in corpus.

T6 — ←DIS *C: three-element competition

C's left-context drives a DIS that simultaneously enacts parse selection. Both parse paths fire:

# AB|C parse: 2-word (subject+modal) substitutes for entire AB
comp_AB_subjs = score_subs(catalog, w0, left_3[:top_n], max_n)
comp_AB_mods  = score_subs(catalog, w1, consensus_left_of_subjs, max_n)
comp_AB = [(f"{s} {m}", s_sc * m_sc) ...]   # 2-word output
# Corpus: "they hadda", "they wont", "sure hadda", "sure wont", "she hadda", ...

# A|BC parse: 1-word subject substitutes for A alone
comp_A = score_subs(catalog, w0, left_of_BC, max_n)   # 1-word output
# Corpus: "well", "cowgirls", "no-one", "madam", "nanobot", "voyage", ...

emit(6, 'COMP_AB', comp_AB)
emit(6, 'COMP_A',  comp_A)

Note the output width asymmetry: COMP_AB produces 2-word bigrams (replacing the whole AB), COMP_A produces 1-word subjects (replacing only A).

T7 — →FF continuation

# FF_AB: AB|C path -- 1-word C-class verb continuations
emit(7, 'FF_AB', score_subs(catalog, w2, ff_ab_pool, max_n))
# Corpus: "bust", "worry", "stay", "talk", "bring", "play", "work", "try", "meet"

# FF_A: A|BC path -- 2-word BC-class (modal+verb) continuations
emit(7, 'FF_A', build_modal_verb_pairs(w1, w2, ...))
# Corpus: "could operate", "didn't operate", "could approve", "could attend", ...

8. Worked Example: "I found my hat"

The 4-word case extends the 3-word timeline with three additional bins (T8–T10). The best parse is A|(B|CD): "i" | ("found" | ("my" | "hat")) — noun phrase "my hat" groups first, then the VP "found my hat", then the subject "i" attaches.

ParseLeft constituentRight constituentCompetition output
ABC|D"I found my" (3 words)"hat" (1 word)3-word trigrams
AB|CD"I found" (2 words)"my hat" (2 words)2-word bigrams
A|BCD"I" (1 word)"found my hat" (3 words)1-word subjects

The best parse "i (found (my hat))" selects A|BCD at the top level and B|CD for the inner span. Full-phrase substitutes:

he'd seen the telegram • haven't announced our engagement • i've taken a lease • we've developed a friendship • you've reached your limits • i'll cook your tongue • i'll fund your expedition

T0–T7: "i found my" processed identically to the 3-word case

Words "i", "found", "my" are processed in the same T0–T7 pattern as "we should go": two FF→DIS convergence cycles, then competition at T6, then FF continuation at T7.

T8 — "hat" arrives; →FF

# Right-contexts of converged determiner class (T7 FF_AB) scored against "hat"
ff_8 = score_subs(catalog, w3, ff8_pool, max_n)
emit(8, 'INPUT', [(w3, 1.0)])
emit(8, 'FF', ff_8)

Corpus result: territory, landlady, concession, ... — noun-class items from the corpus that appear in the same determiner+noun slots.

T9 — ←DIS *D: four-element competition

COMP_L3 (ABC|D) — 3-step cascade — 3-word trigram output
comp_l3_dets  = score_subs(catalog, w2, left_3, max_n)    # det subs for "my"
comp_l3_verbs = score_subs(catalog, w1, consensus_left_of_dets, max_n)
comp_l3_subjs = score_subs(catalog, w0, consensus_left_of_verbs, max_n)
comp_L3 = [(f"{s} {v} {d}", s_sc*v_sc*d_sc) ...]

Corpus result from raster: haven't answered other, we've suggested other, haven't mentioned other, ...

COMP_L2 (AB|CD) — reactivation of T6 COMP_AB — 2-word bigram output
comp_L2 = comp_AB   # same computation -- left_2 context is unchanged

Corpus result: they've arrived, they've answered, they've survived, they've disappeared, ...

COMP_L1 (A|BCD) — reactivation of T6 COMP_A — 1-word subject output
comp_L1 = comp_A   # same computation -- left_1 context is unchanged

Corpus result: fingerprints, you'd, they've, ...

Reactivation principle: When D arrives, the left contexts established at T6 are reactivated — not recomputed. COMP_L2 and COMP_L1 are structurally identical to T6 COMP_AB and COMP_A because the structural position of A and AB relative to the right constituent has not changed. Only COMP_L3 is genuinely new, requiring a 3-step cascade from D's left-context.

T10 — →FF continuation

# ABC|D: D is 1 word -- 1-word noun-class substitutes
emit(10, 'FF_R1', noun_class)
# Corpus: "landlady", "territory", ...

# AB|CD: CD is 2 words -- 2-word (det, noun) bigrams
emit(10, 'FF_R2', det_noun_pairs)
# Corpus: (det+noun pairs from corpus)

# A|BCD: BCD is 3 words -- 3-word (verb, det, noun) trigrams
emit(10, 'FF_R3', verb_det_noun_triples)
# Corpus: "tricked another", "picked another", "punched another", "forgotten another", ...
